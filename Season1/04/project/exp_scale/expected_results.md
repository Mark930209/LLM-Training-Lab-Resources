## 初始 loss 理论值

随机初始化下，lauguage model 的初始 loss ≈ $\ln(V)$：

- 大语料：$\ln(6015) = 8.70$
- 小语料：$\ln(4532) = 8.42$

**判读**：实测初始 loss 应落在理论值 ±0.3 内。**显著偏高**（如 30+）说明
logits 尺度异常或有代码 bug（本篇踩过：gradient accumulation 的 loss 记账错误）。

## 异常判读

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 初始 loss 远超 ln(V) | loss 记账 bug / 初始化异常 | 跑 `diagnose_init.py`；退 LabCoder |
| loss 出现 NaN | lr 过大 / fp16 溢出 / 梯度爆炸 | 检查 grad_clip、AMP scaler；退 LabCoder |
| OOM | batch/seq 过大 | 降 batch_size，再降 seq_len |
| 大语料 loss 反而不降 | 数据加载错误 | 核对 corpus_stats.json 与词表 |
| step 耗时远高于参照 | 被其他进程占用 / thermal throttle | 查 nvidia-smi；退 LabEnv |
