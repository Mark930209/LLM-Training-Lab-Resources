# exp_cpt 预期结果与验收口径（22 篇 Continual Pretraining Lab）

数据未回前只立口径不写结论；结果 JSON 到位后按本文核对，不符则以实测为准
并回写修订说明。底座 Qwen2.5-0.5B（Apache 2.0，494M 参数），bf16 全参
AdamW，RTX 3070 8GB 单卡，bs=2 seq=512（探针实测峰值 6337 MiB / 1340 tok/s）。

## 实验矩阵（21 格，seed 20260929）

| 组 | 格数 | 内容 |
|---|---|---|
| baseline | 1 | 底座 0 步的通用/领域起点 + probe/参数参照 |
| core | 12 | LR 峰值 {1e-5, 3e-5, 1e-4} × replay {0, 5%, 20%, 50%}，统一带 re-warmup |
| rewarm | 1 | rewarm=false 对照（lr=3e-5, replay=20%） |
| mixmode | 1 | 文档级块拼接对照（token 级交错是主方案） |
| vocab | 3 | 扩词表 256 个代码高频标识符，初始化 random/mean/subword_avg |
| failure | 4 | lr=1e-3 擦除 + 降 LR 续训 + 双回退（最近/最早 ckpt） |

每格 token 预算 200K（≈195 步），固定 token 预算口径同 17/20 篇。

## 数据侧验收（meta.data_report）

- 评测集指纹与 17 篇一致（同 nl_eval/code_eval 切分）：`nl_eval_sha256` /
  `code_eval_sha256` 跨篇比对一致。
- 评测集按固定字符切片定义：nl 24000 字符、code 36000 字符；
  跨 tokenizer 对比只看 nats/char（ppl 分母不同不可比）。

## 提纲核心判断的验收口径

**判断：遗忘程度主要由学习率峰值和新旧数据混合比决定，与训练步数次要。**

1. core 矩阵里 nl_ppl 相对 baseline 的涨幅（遗忘）随 LR 峰值单调放大；
   同 LR 下 replay 越高涨幅越小。两个主效应方向必须明确（允许 1 个格反常，
   反常格要在文中标注）。
2. 训练步数次要的证据：eval_curve 中同一格 nl_ppl 的恶化主要发生在
   前 1/3 段（LR 峰值期），后期衰减段平缓。
3. 权衡曲线（领域跌幅 × 通用涨幅）：replay 50% 的格不能在两个轴上都被
   replay 20% 支配（否则"混合比是主效应"的说法要修正为"replay 边际递减"）。

**判断：只报领域评测的 CPT 结论不成立，必须双向验证。**

4. failure 组的 fail 格：code_ppl 可能仍优于 baseline（域内学会了），
   但 nl_ppl 崩（>10 倍 baseline）——这就是"只看领域评测判成功"的陷阱。
   提纲要求的失败案例 ① 即此形态，配提高 replay 后的对照（core 里
   lr=1e-4 rep=0.5 或 nearest）。
5. 失败案例 ②：lr=1e-3 擦除底座知识后，降 LR 续训与回退 checkpoint
   都无法恢复到原通用水平（nl_ppl 回不到 baseline 量级）。
   - 冒烟已见形态：炸点旁 ckpt 本身带毒（重训 step1 即再崩），
     最早 ckpt 恢复更好但也回不到 baseline。正式格复核此形态。

## 各实验的预期方向（详细数值待回填）

| 项 | 预期方向 | 实测（回填） |
|---|---|---|
| baseline nl_ppl / code_ppl | Qwen 底座中文散文 ppl 高于代码（代码有强先验） | nl 72.58 / code 4.39 |
| core lr=1e-5 组 | 遗忘最小，领域提升也小 | |
| core lr=1e-4 组 | 遗忘明显，replay 高可压制 | |
| rewarm=false | 前期 loss 尖峰/不稳定概率高，或终态略差 | |
| mixmode=blocks | 差于 token 级交错（块边界处分布突变） | |
| vocab 三初始化 | subword_avg ≥ mean > random（18 篇方法） | |
| 参数漂移 | lr 越大 mean_change 越大；逐层看顶层/底层差异 | |
| 表示相似度 | 与遗忘同向：nl 崩时 repr_sim 掉 | |

冒烟（20K token 预算，19 步）已验证方向：core 格 repr_sim 0.958、
fail 格 0.036（擦除时表征整体漂走）、recover_low_lr 0.084。

## 显存与降级路线（系列硬要求）

- 实测峰值：bs=2 seq=512 无梯度检查点 ≈6337 MiB（训练）+ 峰值余量；
  bs=4 seq=512 需 9783 MiB 超 8GB（禁用）。
- 降级路线：6GB 卡 → bs=1 seq=512（探针 4930 MiB）或 bs=2 seq=256
  （4930 MiB）；4GB 卡 → 冻结底层只训顶层（PEFT 不展开，指 35 篇边界）。
- 更小底座（Qwen2.5-0.5B 之下无官方更小款）→ 换 17/20 篇的自有小模型
  重跑 core 矩阵（完整复现，但底座先验弱，遗忘幅度不外推）。

## 真实性标签

- 标 REAL：全部21 格单卡实测。
- 标 SCALED：更大底座（1.5B+）的遗忘幅度只给方向性外推，不给数字。
- 标 REFERENCE：公开领域模型的 CPT 配置引用。

## 回填修订记录

（数据回来后逐项核对，不符处在此记录实测值与口径修正。）

### run1（token 级交错混合，`cpt_all_20260929.json`，21 格，核验 FAIL 0）

判读：**混合方式本身是个隐藏变量**。token 级交错把代码/散文逐 token 交错，
制造两种语料都不存在的非自然上下文，其副作用远大于 replay 的保护作用：

- **replay 反向**（与提纲预期相反）：lr=1e-4 档 nl_ppl 涨幅序列
  1.52× / 2.48× / 19.8× / 17.7×（replay 0/5%/20%/50%）——replay 越高
  遗忘越重；lr=3e-5 档同向（1.02/1.12/1.50/2.18）。1e-5 档也同向
  （1.00/1.01/1.03/1.12）。
- **混合方式对照格证明根因**：同 lr=3e-5 rep=0.2，token 交错 nl_ppl
  108.79 / drift 0.369，块拼接（域流在前 replay 在后）nl_ppl 73.12 /
  drift 0.229——块拼接几乎无遗忘（73.12 vs 基线 72.58）。
- **LR 主效应成立**：三档整体涨幅随 LR 单调放大（1e-5 均值 1.04×、
  3e-5 均值 1.45×、1e-4 均值 10.37×）。
- **参数漂移同向**：lr=1e-5 rep0 drift 0.081 → lr=1e-4 rep0 drift 0.847；
  embed_tokens 是漂移最大块（交错 rep0.2 时 0.736）。
- **失败案例①成立**：lr=1e-4 rep0 格 code_ppl 6.32（域内变差）、
  nl_ppl 110.12（1.52×）——大 LR 下"只看领域指标"和"只看通用指标"
  都会误判，必须双向看。
- **失败案例②成立**：fail 格 nl_ppl 67538（930×）；降 LR 续训 43157；
  回退最近 ckpt（step12，炸点旁）76145（毒 ckpt 重训反而更差）；
  回退最早 ckpt（step2）120.73（1.66×）——恢复有梯度但无一回到基线。
- **rewarm 对照**：rewarm_off nl_ppl 108.16 vs rewarm_on 108.79（交错）
  ——交错混合的污染下差异不显，等 run2 文档级再判。
- **vocab 对照（nats/char，跨 tokenizer 唯一可比口径）**：baseline code
  0.3578 / nl 3.2907；core 无扩词表格 code 0.3913 / nl 3.6015；扩词表
  三格 code 0.4237~0.4262 / nl 3.5734~3.5883——**扩词表在 nats/char 口径
  下不优于不扩**（三初始化间差异 <0.6%，无显著区别）。注意 ppl 口径
  不可比（分母 tokenization 不同），ppl 看似扩词表格更好是错觉。

### run2（文档级混合，`cpt_docs_20260929.json`，22 格，核验 FAIL 0）

混合方式改为整篇文档按份额交错（真实 CPT 的 replay 做法）。判读：

- **LR 主效应再次成立且更干净**：三档均值涨幅 0.994× / 1.045× / 2.046×；
  1e-5 档四格全部 ≤基线（0.989~0.998，安全区无遗忘）；3e-5 档 1.019~1.083×；
  1e-4 档 1.50~2.56×。
- **replay 在固定预算下不呈保护效应（提纲预设被推翻）**：lr=3e-5 档
  replay 0/5%/20%/50% → 1.019/1.030/1.048/1.083×，单调恶化；lr=1e-5 档
  轻微保护（0.998→0.989）；lr=1e-4 档噪声大（1.50/2.56/2.00/2.12）。
- **replay 叠加口径探针（`cpt_replay_probe_20260929.json`）**：固定领域数据
  200K、replay 额外叠加（总 250K/400K）——nl_ppl 78.83/89.42，比固定预算
  同档（76.04/78.59）更差。**replay 不保护不是预算挤占的假象**：训练更久
  损伤更大。
- **记忆化证据（`cpt_memcheck_20260929.json`）**：rep0.5 格训练后，replay
  训练文档 ppl **39.0** vs 留出 nl_eval ppl **78.6**（2 倍差距）；code 侧
  仅 4.28 vs 4.52（1.06 倍）。**replay 数据被记忆化而非泛化**——训练损失
  1.36（rep0 格 2.00），loss 降了但保护没有发生。
- **混合方式三格（同 lr=3e-5 rep=0.2）**：interleave 109.39（1.507×）/
  docs 76.04（1.048×）/ blocks 73.12（1.007×）；drift 0.370/0.232/0.229；
  repr 0.888/0.990/0.996。**块拼接（replay 在衰减尾部）几乎无遗忘**。
- **rewarm 对照分离**：on nl 76.04 / repr 0.990 vs off nl 76.96 / repr 0.988
  ——re-warmup 有益但幅度小（1.2%）。
- **vocab（nats/char）**：baseline code 0.3578/nl 3.2907；无扩词表格
  code 0.3601/nl 3.3264；random 0.3863/3.3313、mean 0.3930/3.3261、
  subword_avg 0.3762/3.3259——**三初始化中 subword_avg 最优（code 侧）**
  但全部不优于不扩词表（0.3601）。run1/run2 同向。
- **失败案例（run2 版）**：fail nl 16781（231×）；降 LR 续训 15455（213×，
  无救）；回退最近 ckpt（step12）2178（30×，毒 ckpt）；回退最早 ckpt
  （step2）82.49（**1.136×**，最好但仍高于基线 13.6%）。注意 run2 里
  降 LR 续训/回退都没有 diverge（loss 5~13 区间震荡），是**静默擦除**。
- **自然重复对（噪声底）**：mixmode_blocks 格跨 run1/run2 nl 73.12/73.12
  （逐位一致）、code 4.46/4.47、drift 0.2287/0.2291——seed 固定下确定性
  极好，上述效应远超噪声。
- **参数漂移分层**：embed_tokens 始终最大（rep0.2 docs：0.326；1e-4 档
  1.439）；中层 layers.7~13 次之；repr_sim 与 nl_ppl 同向（0.990→0.983
  对应 1.048→1.083）。
- **双向背离（失败案例①形态）**：lr=1e-4 rep0.05 格 code 涨幅 1.44× vs
  nl 涨幅 2.56×——只看领域评测（code "仅"劣化 44%）会低估通用损伤
  （156%）。

**核心判断被数据修正为三层**：① 遗忘由学习率峰值主导（单调、跨混合方式
稳定）；② replay 的效果取决于它落在学习率调度的哪个阶段与被记忆化还是
泛化——安全 LR 下轻微保护，LR 偏高时被记忆化、加重遗忘，叠加口径同样
如此；③ 混合方式（token 交错/文档交错/块拼接）的效应大于混合比例本身。

### replay 机制判别探针（`cpt_revblocks_20260929.json`，已判别）

反向块（replay 前段=LR 峰值区、域后段=衰减尾部）nl_ppl **89.53**。
对照：baseline 72.58 / rep0 纯域 73.93 / blocks 正向 73.12 / docs 76.04 /
blocks_rev 89.53 / interleave 109.39。

**判别结论：LR 落点说成立，近因说排除**。决定性对照是 rep0（73.93）与
blocks_rev（89.53）：两格都以域数据收尾（近因条件相同），差异只在 replay
数据落在峰值区——89.53 比"完全不 replay"（73.93）还差 21%。即 replay
数据在 LR 峰值区被记忆化后是**净损伤**；只有落在衰减尾部（blocks 正向
的 73.12）才泛化起保护。memcheck 的 train-doc 39.0 vs eval 78.6 与此
一致：峰值区的 replay 训练在"背"数据而不是"学"分布。

**最终核心判断（三层，全部实测支撑）**：
1. 遗忘由**学习率峰值**主导：三档均值 0.99×/1.05×/2.05×，跨混合方式稳定；
   参数漂移、表示相似度同向（embed_tokens 层漂移最大）。
2. replay 的效果**取决于它被训练时所处的学习率阶段**：落在 cosine 衰减
   尾部（低 LR）→ 泛化、几乎无遗忘（73.12）；散布含峰值区（文档交错）
   → 中度损伤（76.04）；主要落在峰值区 → 被记忆化、比不 replay 更糟
   （89.53 vs 73.93）。固定预算与叠加口径同向（78.83/89.42）。
3. **混合方式的效应大于混合比例本身**：token 交错的非自然上下文把遗忘
   放大到 1.51×（109.39），同参数下块拼接仅 1.007×（73.12）。
